# Interact with Nothingness

An independent Next.js and TypeScript project exploring the space between
generative art, AI, and the blank canvas.

## Getting started

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the project.

## Checks

```bash
npm run typecheck
npm run build
```

The AI integration and artwork-generation flow have not been connected yet.
